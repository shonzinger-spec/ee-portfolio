# EE Portfolio - Shon Zinger

Electrical engineering projects by Shon Zinger, a York University EE graduate. Each project is fully virtual and reproducible with free tools: a standalone Python model runs with numpy and matplotlib only, and the simulation, schematic and firmware checks are documented with real output pasted into the project README. No hardware was built.

| # | Project | What it shows | Verification |
|---|---|---|---|
| 01 | [Smart power-monitoring IoT node](01-smart-power-node/) | ESP32 + INA219 power monitor on a 5 V / 2 A rail with an SSD1306 display: 50 mOhm Kelvin shunt, register-level driver, two-task FreeRTOS firmware | main.py self-check, LTspice and ngspice 6/6, host test 33/33, KiCad ERC 0 errors, Wokwi live run |

Highlights of project 01:

- INA219 high-side current sensing: shunt sizing, PGA and calibration choices, saturation handling
- FreeRTOS on the ESP32: two pinned tasks, an overwrite-queue mailbox, a mutex-protected I2C bus
- KiCad schematic generated by script, checked with ERC and a netlist check
- Shunt front-end simulated in LTspice and cross-checked in ngspice
- Wokwi live run of the unmodified firmware against a custom INA219 chip model

## Repository conventions

- A dedicated folder per project (`NN-name/`).
- A standalone main file (for example `main.py`) that runs without a complex install chain.
- A Verification section in each project README, with plots, logs and metrics pasted from real runs.
- A three-sentence Engineering why on the project's trade-offs.
- A Credits section stating what the author did and where AI assisted.
